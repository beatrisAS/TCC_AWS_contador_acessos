INFRAESTRUTURA LOCAL

Nuvem simulada com Docker

O LocalStack cria um ambiente AWS completo no computador, permitindo testar DynamoDB, Lambda e API Gateway sem custos.

docker compose up -d
# Serviços: dynamodb, lambda, apigw
PROVISIONAMENTO

Deploy via cdklocal

Utilizamos o wrapper cdklocal para direcionar o código de infraestrutura (IaC) diretamente para o container local.

cdklocal bootstrap
cdklocal deploy

* Fallback com localStorage garantido para demonstrações offline.
