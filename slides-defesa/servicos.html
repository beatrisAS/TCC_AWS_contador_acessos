03 · SERVIÇOS AWS
Cada serviço tem uma função
e uma justificativa.
Cada serviço foi associado a uma responsabilidade específica no fluxo de acessos.
01

API Gateway

O QUE É

Porta de entrada para APIs HTTP e REST.

USO NO PROJETO

Expõe o endpoint GET /acessos.

POR QUE

Integração simples entre front-end e Lambda.

02

AWS Lambda

O QUE É

Computação Serverless orientada a eventos.

USO NO PROJETO

Executa o incremento do contador.

POR QUE

Escala sob demanda sem servidor permanente.

03

DynamoDB

O QUE É

Banco NoSQL gerenciado e escalável.

USO NO PROJETO

Persiste o total no item id=hits.

POR QUE

Baixa complexidade e atualização atômica.
