03 · ARQUITETURA

A solução separa entrada,
processamento e dados.

CAMADA DE ENTRADA
01

Amazon API Gateway

Funciona como a porta de entrada para as requisições HTTP, gerenciando o tráfego e protegendo o backend.

CAMADA DE LÓGICA
02

AWS Lambda

Executa o código do contador apenas quando acionada, realizando o incremento sem necessidade de servidores ligados.

CAMADA DE PERSISTÊNCIA
03

Amazon DynamoDB

Banco de dados NoSQL de alta performance que armazena o total de acessos de forma persistente e escalável.

Infraestrutura complementar: S3, CloudFront, IAM e CloudWatch.
